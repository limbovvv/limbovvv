## Практические задачи

### Диагностика сбоя веб-приложения: Kubernetes + MySQL

Участвовал в разборе цепочки отказа: длительная выгрузка с блокировками таблиц → накопление соединений MySQL → ошибки приложения → потеря готовых экземпляров frontend и HTTP 503.

- Для резервного копирования внедрены согласованная выгрузка InnoDB без блокировки таблиц, защита от одновременных запусков, тайм-аут и проверка ошибок.
- Целостность копии проверена по SHA-256, gzip и структуре SQL. Тестовое восстановление остаётся отдельным этапом проверки.
- Проверки Kubernetes перенесены на статический endpoint; для обновления frontend настроен `maxUnavailable: 0`.
- После изменений проверены готовность четырёх экземпляров frontend и ответы HTTP 200 у сайта и API. Изменение манифеста в репозитории оставалось отдельной задачей.
